Strategic Architectural Decisions

Target Environment

Hybrid Local-First Dev, Cloud-First Verify

Develop on local SQLite + in-memory vector store + Portkey gateway during Days 1–7 to circumvent Azure free-tier quota lockouts (AI Search 50MB limit, Cosmos 1000 RU/s). Verify against personal Azure trial / employer sandbox in Days 8–10 via .NET provider abstractions.

Zero code changes: switch database and vector providers via environment variables.
Orchestration

.NET 8 Semantic Kernel with Portkey

Adopt Microsoft Semantic Kernel in C# directly inside the ASP.NET Core 8 Web API. Plugs seamlessly into the employer-hosted Portkey LLM gateway using an OpenAI/Anthropic-compatible client. Avoids introducing an unneeded Python sidecar.

100% alignment with team's deep C# background (Saravanan, Jegan, Smita).
Feature Scope

Strictly Conversational Intake

Focus exclusively on the Conversational Intake pillar: CRM-assisted start, meeting notes extraction, clarifying questions below the 0.70 confidence floor, and value correction with downstream conflict checking. Stubs only for later pillars.

14 inferable attributes across Individual and Joint WROS registrations.
LLM Credentials

Employer-Hosted Portkey Gateway

Utilize the existing employer-hosted Portkey gateway with configurable model routing behind the scenes. Stored in local environment via dotnet user-secrets, transitioning to Azure Key Vault for cloud staging.

Centralized model routing, fallbacks, telemetry, and rate-limit buffering.

Quality Gates & Acceptance Criteria

🔒

Deterministic Redaction

Zero PII transmitted across the LLM prompt boundary. 100% test pass on role-token and vaulted-flag conversion.

✍️

Advisor Confirmation Rule

Zero values written to permanent record without explicit advisor action (Confirm or Confirm all).

🎯

Confidence Floor (0.70)

Ambiguous remarks strictly trigger clarifying questions instead of hallucinated field proposals.

📎

Audited Citation Grounding

100% of CRM-derived values carry source chunk ID, timestamp, and verbatim heard text.

⚡

Dual-Provider Persistence

Application runs seamlessly on local SQLite development database and Azure Cosmos DB Serverless.

🚫

Submission Blocker

The form submission remains locked while any field is in an extracted_unconfirmed state.
